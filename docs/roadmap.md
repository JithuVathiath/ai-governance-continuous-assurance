# Roadmap

Version 0.1.0 deliberately prioritises a small, auditable core over a large platform surface.

## Next

- Signed evidence manifests and Sigstore policy-pack releases
- External ledger-head anchoring and append-only storage adapters
- Open Policy Agent or CEL expression support with safe evaluation limits
- Policy-pack migration and historical replay tests
- CycloneDX evidence and model-component inventory export
- First-class reviewer attestations and segregation-of-duties checks
- Connectors for model registries, CI, ticketing, security scanners, and data catalogues
- Additional public mappings reviewed by qualified subject-matter experts

## Explicitly Out of Scope

- Automated legal advice or regulatory classification
- ISO certification or conformity assessment
- A universal numerical “trust” or “compliance” score
- Storing confidential production evidence in this demonstration repository
